edge-metrics demo

Send a real request through Envoy Gateway to one of the demo services.

Pick a route and hit "Send request".

Non-mTLS routes also simulate the matching Cloudflare Logpush push for the same request (see demo-ui/server.mjs) — check Grafana Explore (Loki) and the Edge Metrics dashboard at localhost:3000 to see both logs land, categorized.
